01 — Overview

What is Rizza?

Rizza is an AI-native talent marketplace combining verified candidate profiles, behavioral assessments, a smart ATS, and gamified hiring — all in one platform for both web and mobile.

Kanban pipeline, video pitch player, scorecards, and offer generation in one place.

Digital Verification Vault

02 — Product Verticals

Six Core Product Areas

Each vertical is a distinct product that works together as one platform — think LinkedIn + Greenhouse + HackerRank + Checkr, combined.

🧬

Professional Identity & Storytelling

Candidate "Life Page" with STAR story builder, proof-of-work portfolio, workstyle and motivation surveys, and AI-assisted narrative generation.

📊

Multi-Dimensional Assessments & Benchmarking

Technical coding sandbox, culture fit, persona, communication, and leadership tests. Global percentile benchmarks and verified skill badges.

🎯

AI Job DNA Matching Engine

Employers define a "Job DNA" via a signal weight matrix. Candidates are scored and ranked using vector embeddings + weighted criteria across 7+ dimensions.

🔀

ATS & Recruitment Pipeline

Kanban pipeline, weekly curated matches, candidate comparison matrix, 1-minute video pitch player, interview scheduling, and scorecards.

🔐

Digital Vault & Verified Offers

Encrypted document vault, ID/education/salary verification via OCR, background check integrations, dynamic offer letter builder, and e-signing.

🏆

Brand Challenges & Arcade

Employer-sponsored hackathons, coding competitions, real-time leaderboards, gamified badge system, community feed, and talent pooling from challenge winners.

🌐 Public / Marketing

Unauthenticated marketing site: Homepage, candidate & employer landing pages, pricing, blog, help center, legal pages, and 404. SSR via Next.js for full SEO.

Internal operations: user management, KYC, skills/role taxonomy, question bank, assessment builder, trust & safety, job moderation, revenue dashboards, and audit logs.

Full recruitment lifecycle: company setup, Job DNA Studio, ATS Kanban, interview management, verification oversight, offer generation, and analytics. 28 screens have dedicated mobile layouts.

Full career platform: profile, STAR storytelling, assessments, score benchmarking, job matching, applications, video pitch, interviews, verification, arcade, and portfolio.

06 — System Architecture

How the System Works

Single Turborepo monorepo hosting Web, Mobile, and Backend. All share TypeScript types. Traffic flows through Cloudflare to API Gateway to 9 backend services.

CLIENT LAYER Web: Next.js 14 Mobile: React Native (iOS + Android) SSR for marketing pages Expo SDK — Camera, Push, Navigation React SPA for dashboards Shares TypeScript types with Web + API | | └──────────────────────┬───────────────────────┘ | CLOUDFLARE CDN + WAF + DDoS Protection + SSL | API GATEWAY — Auth, Rate Limiting, Routing | tRPC / GraphQL / REST / WebSockets | BACKEND SERVICES (NestJS Modular Monolith) 1. Auth & RBAC Service 6. Media & Video (S3 + HLS) 2. Candidate Profile + STAR 7. Verification + E-Sign 3. Assessment Engine 8. Arcade + Leaderboard (Redis) 4. AI Job DNA Matching (LLM) 9. Billing + Subscriptions (Stripe) 5. ATS Pipeline + Kanban | | | PostgreSQL 16 Redis Cluster pgvector (DNA Embeddings) Primary Database Cache + Queues + Semantic Match Search Multi-Tenant Leaderboards (ZSET) Cosine Similarity Ranking
🔒

Multi-Tenant by Design

All employer data is isolated by organization. Candidates are global. No data leakage between tenants.

⚡

Shared Types Monorepo

Web, Mobile, and Backend share Zod schemas via Turborepo — no duplication, no drift, fully type-safe.

🧠

AI-Native Matching

Profiles and Job DNA are embedded via OpenAI — cosine similarity + signal weighting returns ranked matches.

📹

Video Pitch Pipeline

Client compresses → S3 pre-signed upload → AWS MediaConvert HLS → employer streams directly.

08 — MVP Strategy

What to Build First

Two delivery options. Option A gets you to market with the full core value in 5–6 months. Option B is the complete platform.

Option A — Web MVP First
Core Platform Launch
5–6 months
Phases 1–6 · Web only · ~3,800 hrs
  • Public marketing website (all 12 screens)
  • Full candidate profile + STAR storytelling studio
  • 5-type assessment engine + percentile benchmarks
  • Employer Job DNA Studio + AI JD generation
  • Full ATS Kanban pipeline + candidate comparison
  • Interview scheduling + 1-min video pitch (web)
  • Stripe billing + employer subscriptions
  • Mobile app added in Full Build (Phase 10)
Option B — Full Platform
Complete Web + Mobile
12–15 months
All 11 phases · All 236 screens · iOS + Android
  • Everything in Option A, plus:
  • Digital Vault + full verification + e-signature offers
  • Brand Arcade + challenge leaderboards + badges
  • Candidate portfolio gallery
  • Super Admin operations suite (all 25 screens)
  • Executive analytics + attrition prediction
  • React Native iOS + Android mobile apps
  • Vanity URLs + public profile sharing

Why These Are Real 2026 Timelines

AI coding agents (Cursor, GitHub Copilot, Claude Code), pre-built component libraries (Shadcn UI, Radix), type-safe API layers (tRPC + Prisma), and boilerplate generators mean a single focused developer can ship screens 2–3x faster than traditional timelines. These timelines factor that in — they are not inflated.
